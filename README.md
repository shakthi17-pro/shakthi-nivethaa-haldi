# Shakthi & Nivethaa — Cinematic E-Invite Starter

## Run locally
1. Install Node.js 20+.
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown by Next.js.

## Add your own assets
- Put couple photos in `public/images/`.
- Put the wedding music file at `public/music/wedding.mp3`.
- Replace the CSS temple placeholder with layered transparent PNG/WebP artwork for a more realistic Meenakshi Temple effect.
